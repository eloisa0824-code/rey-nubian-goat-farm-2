# Rey Nubian Goat Farm Website

Responsive static website for Rey Nubian Goat Farm in La Union, Philippines.

## Offerings
- Goat milk
- Live goats
- Investor and farm partnership inquiries

## Run locally
Open `index.html` in a browser or serve this folder with any static web server.

## Before publishing
- Replace the sample email link in `index.html` with the farm's verified contact channel.
- Add the official Facebook page/profile link and verified contact details.
- Confirm current goat milk and live-goat availability, pricing, and terms.
- Add farm-owned photography when available.

The supplied farm logo is stored in `assets/rey-nubian-logo.jpg`. Farm and livestock photos currently use Unsplash image URLs.
